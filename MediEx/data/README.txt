Put the Kaggle CSV files in THIS folder:

  Training.csv                 (required)
  Testing.csv                  (optional)
  Symptom-severity.csv         (optional, better weights)
  symptom_Description.csv      (optional, disease descriptions)
  symptom_precaution.csv       (optional, precautions)

Kaggle datasets that work:
  - "Disease Prediction Using Machine Learning"  (kaushil268)   -> Training.csv, Testing.csv
  - "Disease Symptom Prediction"                  (itachi9604)   -> severity, description, precaution
  - "Disease Symptom Prediction"                  (karthikudyawar) -> all of the above in one

File names are matched without caring about upper/lower case.
Check each dataset's license before putting the data in a public repository.
